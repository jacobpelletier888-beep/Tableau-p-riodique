# Chimie — Tableaux

Petite application web pour consulter deux tableaux de chimie.

## Utilisation

Ouvre simplement le fichier **`index.html`** dans n'importe quel navigateur
(double-clic). Aucune installation ni serveur nécessaire.

## Fonctionnalités

- **Dashboard** d'accueil avec deux boutons :
  - 🧪 **Ions polyatomiques** — les cations et anions les plus courants, regroupés par charge (1+, 1−, 2−, 3−).
  - 🔬 **Tableau périodique** — les 118 éléments, colorés par catégorie. Touche un élément pour voir sa fiche (numéro atomique, masse, catégorie, période, groupe).
- Une **flèche de retour** (← Retour) en haut de chaque tableau pour revenir au Dashboard.

L'application est contenue dans un seul fichier `index.html` (HTML + CSS + JavaScript, sans dépendance externe).
